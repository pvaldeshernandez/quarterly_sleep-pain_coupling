## Quick Start

```bash
git clone git@github.com:pvaldeshernandez/quarterly_sleep-pain_coupling.git
cd quarterly_sleep-pain_coupling

conda env create -f environment.yml
conda activate sleep-pain-coupling
```

Place the data files provided by Pedro into `data/original/` and the neuroimaging directories (`fmri_contrasts/`, `spm_nomask/`, `vbm/`, `atlases/`) into `data/`. Then run the pipeline step by step:

```bash
cd python
python step0_extract_data.py
python step1_factor_analysis.py
python step2_prepare_varx_data.py
python step3_fit_coupling_model.py
python step4_contrast_moderation.py
python step5_extract_sp_rois.py
python step6_fit_sp_moderation.py
python step7_sp_moderation_jn.py
python step8_extract_ps_rois.py
python step9_fit_ps_moderation.py
python step10_ps_moderation_jn.py
python step11_remaining_figures.py
```

Total runtime: approximately 30 minutes on a 4-core machine with 16 GB RAM.

## MATLAB Pipeline

The MATLAB code preprocesses raw MRI data and creates the ROI masks and first-level contrast images that the Python pipeline reads. It is not needed for the statistical analysis — only for reproducing the neuroimaging preprocessing from raw DICOM files.

### Requirements

- MATLAB R2018b or later
- SPM12 (https://www.fil.ion.ucl.ac.uk/spm/software/spm12/)
- FSL (for CeA atlas registration only)

### Pipeline Steps

| Step | Script | Description |
|------|--------|-------------|
| 0 | `preprocessing/script_study.m` | Main driver — configure paths and run all steps |
| 1-9 | `preprocessing/*.m` | DARTEL pipeline: segmentation, template, normalization |
| 10 | `first_level/run_first_level_glm.m` | First-level GLM (pain stimulation paradigm) |
| 11 | `nomask_reestimation/run_nomask_reestimation.m` | Re-estimate without GM mask for subcortical ROIs |
| 12-14 | `rois/create_*.m` | Create spherical and atlas-defined ROI masks |
| 15 | `rois/extract_*_roi_values.m` | Extract BOLD and GM volume values |

---

## Output Organization

The pipeline writes to three directories:

- **`data/`** — Only Step 0 writes here. Contains the extracted long-format CSV that all downstream steps read.
- **`derivatives/`** — Intermediate outputs passed between steps: factor scores, processed data, posterior draws, ROI values, JN grids.
- **`results/`** — Paper outputs: every table (CSV), every figure (PNG), and every text number (CSV) reported in the manuscript. Each file is prefixed with its step number.

## Data Availability

The data that support the findings of this study contain protected health information from human subjects and cannot be shared publicly due to IRB and HIPAA restrictions. De-identified data are available from the corresponding author upon reasonable request, subject to institutional data use agreements.

The following data files are needed to run the pipeline:

| File | Description | Size |
|------|-------------|------|
| `data/original/participants_wideformat.xlsx` | Legacy wide-format dataset (all baseline + quarterly variables) | ~4 MB |
| `data/original/UPLOAD2_Data_Dictionary.xlsx` | Variable definitions and coding | ~220 KB |
| `data/fmri_contrasts/` | GM-masked first-level SPM contrast images (one `con_0001.nii` per subject) | ~41 GB |
| `data/spm_nomask/` | Unmasked re-estimated contrast images | ~200 MB |
| `data/vbm/` | Smoothed modulated grey matter images (`smwc1*_ses-01_T1w.nii`) | ~1.7 GB |
| `data/atlases/` | Probabilistic arousal ROI atlases (PBN, SI-BF, CeA, BNST, LH) | ~330 MB |
