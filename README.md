# Quarterly Sleep-Pain Coupling in Knee Pain

Reproducible analysis code for:

> Valdes-Hernandez PA, Montesino-Goicolea S, Li X, Fillingim RB, Cruz-Almeida Y. **Quarterly Sleep-Pain Coupling in Knee Pain: Pain-to-Sleep Dominance and NAcc-Gated Sleep-to-Pain.** *[Journal TBD]*, 2026.

---

## Quick Start (Synthetic Data Demo)

Run the full Python analysis pipeline on simulated data — no real data needed:

```bash
# Clone the repository
git clone git@github.com:pvaldeshernandez/quarterly_sleep-pain_coupling.git
cd quarterly_sleep-pain_coupling

# Create and activate the conda environment
conda env create -f environment.yml
conda activate sleep-pain-coupling

# Run the full pipeline on synthetic data
cd python
python main.py --synthetic
```

This generates all results and figures in `results/` and `figures/` using parametrically simulated data (see [Synthetic Data](#synthetic-data)).

## MATLAB Pipeline

### Requirements

- MATLAB R2018b or later
- SPM12 (https://www.fil.ion.ucl.ac.uk/spm/software/spm12/)
- FSL (for CeA atlas registration only)

### Pipeline Steps

The MATLAB code preprocesses raw MRI data and extracts ROI values. Run from the `matlab/` directory.

| Step | Script | Description |
|------|--------|-------------|
| 0 | `preprocessing/script_study.m` | **Main driver** — configure paths and run all steps |
| 1 | `preprocessing/segment_T1ws.m` | Unified segmentation of T1w images |
| 2 | `preprocessing/create_T1w_template.m` | DARTEL template estimation (6 iterations) |
| 3 | `preprocessing/slice_timing.m` | Slice timing correction (Philips interleaved) |
| 4 | `preprocessing/realign_unwarp.m` | Motion correction with unwarping |
| 5 | `preprocessing/coregister_fMIRs_to_T1ws.m` | Functional-to-structural coregistration |
| 6 | `preprocessing/segment_fMRIs.m` | Segment mean functional images |
| 7 | `preprocessing/get_deformations.m` | Estimate DARTEL flow fields |
| 8 | `preprocessing/deform_all.m` | Push-forward normalization to MNI (3mm isotropic) |
| 9 | `preprocessing/register_T1w_template_to_MNI.m` | Template-to-MNI affine registration |
| 10 | `first_level/run_first_level_glm.m` | First-level GLM (5-block pain stimulation) |
| 11 | `nomask_reestimation/run_nomask_reestimation.m` | Re-estimate without GM mask |
| 12 | `rois/create_krause_spherical_rois.m` | Create 6 Krause et al. spherical ROIs |
| 13 | `rois/create_acc_spherical_roi.m` | Create ACC spherical ROI |
| 14 | `rois/create_*_atlas_roi.m` | Create 5 Lynch et al. atlas-defined ROIs |
| 15 | `rois/extract_*_roi_values.m` | Extract BOLD and GM volume values |

**Note:** The first-level GLM replaces CONN toolbox — no CONN dependency is needed. All SPM batch jobs are created programmatically via `spm_jobman`.

## Python Pipeline

### Requirements

```bash
conda env create -f environment.yml
conda activate sleep-pain-coupling
```

Key packages: PyMC 5.27.1, ArviZ, NumPy, SciPy, pandas, matplotlib.

### Running the Pipeline

```bash
cd python

# Full pipeline with real data
python main.py

# Full pipeline with synthetic data
python main.py --synthetic

# Start from a specific step (e.g., regenerate figures only)
python main.py --synthetic --step 6

# Run with LOO-CV model comparison (adds ~30 min)
python main.py --synthetic --loo
```

### Pipeline Steps

| Step | Script | Description | Time (synthetic) |
|------|--------|-------------|-----------------|
| 01 | `01_prepare_data.py` | Factor analysis, within-person decomposition | ~5 sec |
| 02 | `02_fit_coupling_model.py` | Bayesian VARX(1) fitting | ~2 min |
| 03 | `03_contrast_moderation.py` | Pain localization JN analysis | ~5 sec |
| 04 | `04_fmri_sp_moderation.py` | 7 fMRI ROI moderation models | ~15 min |
| 05 | `05_arousal_ps_moderation.py` | 10 arousal pathway models | ~20 min |
| 06 | `06_generate_figures.py` | All figures from saved results | ~10 sec |

## Synthetic Data

The `simulate/generate_synthetic_data.py` script generates parametrically simulated data from the fitted model parameters (Table 4 of the manuscript). This enables the Python pipeline to run end-to-end without real participant data.

The synthetic data preserves:
- Sample size and observation structure (N=229, median 9 quarterly visits)
- Demographic distributions (age, sex, race matching Table 3)
- VARX(1) dynamics with known ground truth parameters
- fMRI subsample (N=174) with ROI values correlated with coupling random effects
- Recoverable moderation signals for left NAcc and ACC

Ground truth parameters are saved in `data/synthetic/ground_truth.json` for parameter recovery verification.

To regenerate synthetic data with a different random seed:
```bash
python simulate/generate_synthetic_data.py --seed 123
```
